## Placement notes

- Catalog units are meters; each pivot is centered horizontally at the lowest point.
- Floor, wall, and roof triangle roles are generated from GLB geometry and used by both the viewport proxy and server collision.
- Use the Buildings tab. The existing lazy portrait path generates and caches previews with its single shared renderer.
- Road, bridge, and tunnel models remain out of this collection; they need road-specific surfaces and scale validation.
