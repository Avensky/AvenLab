# Hero selection layout

Current controls are documented in [MENU_NAVIGATION_AND_CHAT.md](MENU_NAVIGATION_AND_CHAT.md).

The large hero/role title remains at upper left. Portraits keep their original
artwork footprint without name bands or an enclosing mobile box. Role filters
now sit above the grid. Environment or Recon CAN controls sit below it, and
teammate cards are centered above the preserved footer. The vehicle bar is removed.

Navigation follows visible horizontal rows and three-column grid lines. The
single selected 3D vehicle still rotates in the existing garage, with reduced
motion respected. Chat now rests as a launcher and briefly opens for messages
or validated player activity. Signal Recon no longer visits its legacy setup
screen in the normal Play/Back flow.
