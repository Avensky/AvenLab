# Static background vehicles

vehicleCatalog.ts approves five visual sources and sizes/LOD budgets. vehicleTemplate.ts preserves imported hierarchy, negative transforms and cached materials. VehicleProps.tsx instances distant six-box proxies and limits full models.

## How to edit

These are decorative traffic/background props: no player controls, audio, lights, AI or physics. Do not flatten mirrored/negative-scale hierarchies. To make real traffic, add a separate server-owned actor system and explicit colliders. Auto near models are budgeted; selecting a source may show one full preview.
