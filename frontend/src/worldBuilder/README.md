# Universal world editor

document/ is pure schema/geometry; state/ owns drafts/history/preferences; panels/ owns authoring UI; scene/ owns preview rendering. roads/, models/, vehicles/ supply asset-specific geometry/catalogs.

## How to edit

Editing world in the header is the single source-map selector. Export title under Files labels the draft only. Header Inspector hides/shows the right sidebar; Minimize changes its width. Inspector tabs separate Selection, Spawns, World, Scene, Snapping and Files. Use [editor guide](../../../docs/UNIVERSAL_WORLD_EDITOR.md) and [spawn guide](../../../docs/SPAWN_EDITING.md).
