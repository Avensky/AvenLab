# Draco glTF decoder

These decoder files are redistributed from the installed Three.js 0.181.2 package, examples/jsm/libs/draco/gltf/. The Draco project distributes them under Apache License 2.0; see LICENSE.

Source: https://github.com/google/draco
Three.js distribution: https://github.com/mrdoob/three/tree/r181/examples/jsm/libs/draco

Keep the wrapper and WASM binary together, and refresh the complete set when upgrading Three.js. The JS decoder supports environments without WebAssembly. No encoder is shipped.
