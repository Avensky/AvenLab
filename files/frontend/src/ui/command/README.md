# command

CommandLine.tsx is the active driving research terminal. index.ts is its public API. It reads canDataStore and input player flags. Mark forwards to the Recon marker owner, which serializes/retries posts using server timestamps; it is enabled only for the active research session.

A live window keeps 1,000 log lines / 20,000 appended frames and reports dropped old display frames. Explicit playback imports remain lossless. Full recordings belong to the data service. Summary/frame/raw/playback/diff/heatmap bodies here remain placeholders; use the full Recon workspace for those workflows. Application menus and mission apps are separate.
